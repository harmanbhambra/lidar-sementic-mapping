# LiDAR Semantic Mapping Project

## Overview
This project focuses on building a 3D semantic representation of environments using LiDAR and vision-language models.

## Objectives
- Understand LiDAR data and point cloud representation
- Set up Ouster LiDAR SDK
- Capture and process point cloud data
- Integrate semantic understanding using ML models

## Progress
- [x] Studied LiDAR working principles (Time-of-Flight)
- [x] Explored Ouster SDK repository
- [x] Set up project structure
- [ ] Connect to LiDAR sensor
- [ ] Capture real-time scans
- [ ] Convert scans to point cloud (XYZ)

## Pipeline
LiDAR → Scan → XYZ Conversion → Point Cloud → Semantic Mapping
